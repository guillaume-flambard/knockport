# assets

Audio for the demo video.

- `background.mp3` — background music, mixed low by `pnpm demo:render`.
- `whoosh.mp3` — a short transition sound, played at each scene cut.

## Current track

- **"Thinking Music"** by Kevin MacLeod (incompetech.com)
- Licensed under **CC BY 3.0** — attribution required.
- https://incompetech.com/music/royalty-free/mp3-royaltyfree/Thinking%20Music.mp3

The demo video carries the attribution in its end card / notes. If you swap
the track, keep the attribution for whatever you replace it with.

## whoosh.mp3

Generated locally with ffmpeg (a short filtered sweep). No license to manage.
Replace it with a nicer transition sound if you want one.
